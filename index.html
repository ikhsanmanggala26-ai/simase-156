Deployment Google Apps Script Anda Perlu Diperbarui (Versi Baru)

Server Google Apps Script merespons "Aksi tidak dikenal: pull_db". Artinya kode Code.gs yang aktif di URL Web App Anda belum memiliki fitur tarik data terbaru.

Cara Pemasangan Backend Google Apps Script (3 Menit):
  1. Buka script.google.com menggunakan akun Google sekolah/operator, lalu klik Project Baru (+ New Project).
  2. Hapus seluruh isi bawaan pada file Code.gs, lalu klik tombol "Salin Kode Code.gs" di bawah ini dan tempelkan (Paste).
  3. Klik tombol biru Terapkan (Deploy) → Deployment baru (New deployment).
  4. Pilih jenis Aplikasi web (Web app) → Jalankan sebagai: Saya (Me) → Yang memiliki akses: Siapa saja (Anyone) → Klik Terapkan dan berikan izin akses (Authorize).
  5. Salin URL Aplikasi Web yang muncul, tempelkan ke Tab 1 di atas, lalu klik Simpan Konfigurasi → Uji Koneksi.
